# Proton Drive file version recovery

Issue #509. Verified 2026-11-19 from official help, not a signed-in recovery test.

https://proton.me/support/version-history

The help documents previous-version creation when replacing an uploaded file, browsing, downloading and restoring versions. Restoring does not remove newer versions. Free accounts retain up to 10 versions per file for up to 7 days, with no configurable retention. Listed paid plans allow up to 200 versions and up to 10 years, with adjustable settings. This verifies the capability, not unlimited retention or a complete backup guarantee. Docs and Sheets use editor-level history instead of the uploaded-file context menu. Other pricing, platform and capability snapshots remain unchanged. No user files were uploaded, restored or deleted.
