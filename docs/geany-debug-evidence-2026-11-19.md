# Geany Debugger plugin

Verified 2026-11-19 from Geany-Plugins 2.1.0. Existing debugger unknown → partial.

- https://github.com/geany/geany-plugins/blob/2.1.0/debugger/README: Debugger is a plugin, supports only GDB; other backends are planned, not shipped support. Lists breakpoints, watches, threads and stack information; requires libvte, GTK 3 and POSIX API.
- https://github.com/geany/geany-plugins/releases/tag/2.1.0: collection requires Geany 2.1. Do not treat the README's historical >=0.21 as this release's minimum.

Partial reflects optional plugin and backend/platform prerequisites. No claim of stock Windows package support, all-debugger support, bundled GDB, or parity with a full IDE. No installation or debugging execution was performed. Other Geany features, metadata and old translations remain unchanged.
