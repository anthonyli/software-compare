# GeanyVC Git integration

Verified 2026-11-19 from released Geany-Plugins 2.1.0. Existing Geany git_integration unknown → partial.

- https://github.com/geany/geany-plugins/blob/2.1.0/geanyvc/README: supports Git diff/log/status/revert/commit and other listed actions through the VCS toolchain. Requires installing and enabling GeanyVC in Plugin Manager. Describes a small subset, not all VCS features.
- https://github.com/geany/geany-plugins/releases/tag/2.1.0: this plugin collection requires Geany 2.1. The README's historical Geany >=0.19 requirement is not promoted as the minimum for this release.

Partial means optional plugin + external Git toolchain, not core built-in complete GUI or all Git operations. No claim about all OS packages bundling the plugin, external diff tools being mandatory, or support for other unknown editor capabilities. The Geany manual fetch was unavailable and plugin webpage timed out; the released official repository README is the evidence used. No software installed or Git operations performed in any user project. Existing translations and other feature values retained.
