Checked 2026-11-18 against official stable v1.16.2, commit b555312d70d7ff017f866649a7e7167af4eb8fca.

The viewer supports accepting clipboard changes from the server and sending them to the server, enabled by default; MaxCutText limits accepted updates. This confirms basic clipboard synchronization, not file transfer, arbitrary rich-format interchange, or all server configurations.

FullScreenMode selects Current, Selected or All local monitors for full-screen viewing; FullScreenSelectedMonitors chooses the local monitor list. Mark the combined multi-monitor capability partial, with its actual viewer option in the visible note. This is not a claim of arbitrary independent remote-monitor mapping or every server supporting desktop resizing.

Only these two feature cells and the evidence source change. Preserve encryption, server setup, platform, pricing, all other features and shared English dictionary. No software installed or remote connection attempted; no production site visited.
