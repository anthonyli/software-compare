# Flameshot color picker and screenshot history

Issue #486. Official documentation checked 2026-11-19 (Asia/Shanghai), not an installed-app test.

https://flameshot.org/docs/guide/key-bindings/

The Local section explicitly lists GUI-mode `g` for screen color picking and `Shift` + `Print` for Screenshot History. These directly establish the two feature cells. The picker is available within the capture GUI, not evidence of a standalone utility. History availability does not establish unlimited retention, a complete archive, cloud synchronization or privacy guarantees. Upload and dedicated window capture remain unknown. No other product metadata or shared translation changes.
