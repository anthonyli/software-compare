# Lite XL gitstatus

Verified 2026-11-19. Existing git_integration unknown → partial.

Official source pinned at https://github.com/lite-xl/lite-xl-plugins/blob/6e4aa640d679decd67d2c0b677ede52ef70a7bf9/plugins/gitstatus.lua . The mod-version:3 plugin executes external git rev-parse and git diff --numstat, updates tree modification colors and adds a statusbar branch/insertion/deletion indicator. It does not implement commit or branch-management commands.

Partial records this optional plugin's limited status integration, not core bundled support or a complete Git GUI. It is not a claim that no other plugin can perform more operations. Do not imply all repository states, binary changes, worktrees or every platform were tested. No actual plugin installed or executed; only official source inspected. All other Lite XL values and old translations remain unchanged.
