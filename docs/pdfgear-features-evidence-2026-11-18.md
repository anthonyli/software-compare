# PDFgear Windows capabilities

Checked 2026-11-18 for Issue #417.

- https://www.pdfgear.com/pdfgear-for-windows/index.htm explicitly documents highlights, underlines, comments and text boxes; OCR making scanned PDFs searchable/selectable; and form filling with text, checkmarks and symbols even without interactive fields.
- https://www.pdfgear.com/windows-user-guide/fill-out-pdf-form.htm documents the Windows Form tab and adding text, images, signatures and icons.

Only annotate, ocr and form_fill change from unknown to yes. Each retains an explicit Windows scope note; this is not a claim of feature parity on every listed platform. No guarantee of all dynamic forms, OCR languages or recognition accuracy is implied. No change to privacy, price, AI connectivity or platform fields. No production site or installed app was tested. Shared translations remain byte-identical.
