# LibreOffice PDF signing evidence

Issue #494. Verified from official LibreOffice 26.8 Help, not an installed-app test.

https://help.libreoffice.org/latest/en-US/text/shared/01/signexistingpdf.html

The documented Sign Existing PDF command opens the PDF in Draw in read-only mode for digital signing. This confirms signing capability, not ordinary editing of the PDF content. Signing requires a suitable digital certificate; this is not a claim of legal validity or configuration-free operation. Other feature cells, release, price, platforms and license remain unchanged. No document was signed during this research.

Certificate prerequisite and validation boundaries: https://help.libreoffice.org/latest/en-US/text/shared/guide/digital_signatures.html
