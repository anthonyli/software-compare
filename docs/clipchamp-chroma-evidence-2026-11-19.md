# Clipchamp chroma key evidence

Verified 2026-11-19. Only `clipchamp.features.chroma_key` changes from unknown to yes.

- https://clipchamp.com/en/features/green-screen-video-editor/ explicitly presents a free green-screen editor and supports green, blue and red screen footage.
- https://support.microsoft.com/en-gb/clipchamp/how-to-use-the-green-screen-effect-in-clipchamp explains importing suitable footage, layering background media below it, applying the effect and adjusting threshold/color. It describes personal-account steps with the same principles applicable to work/school.

This is editing prerecorded colored-background footage, not automatic removal of arbitrary backgrounds or live webcam replacement. The free effect does not imply all stock assets or export resolutions are free. Other capabilities and all existing pricing/platform fields remain unchanged. No generic effects or 4K entitlement is inferred from this narrow verification.

Tests verify status, sources and unchanged unknowns; browser regression covers English/Chinese and desktop/mobile widths. No shared translations, production configuration, production access or video rendering.
