# Bear Web Clipper 核实

2026-11-16，仅查官方文档，未安装或运行扩展。

https://bear.app/faq/browser-extensions/ 明确整页（含可选图片）和选区剪藏、标签与标题/URL模式，因此 web_clipper 从 unknown 改为 yes，移除过时的“首页未确认”说明。

依赖同设备安装 Bear 应用。文档列 Safari（macOS/iOS/iPadOS）、Chrome/Chromium 与 Firefox；不据浏览器支持推断 Bear 在 Windows/Android 可运行。网页清理为尽力处理，不保证任意页面完整还原。

官方声明从 Bear 2.6.3 起 Web Clipper 2.0 在本机处理页面，旧版使用服务器处理。该声明限定剪藏处理，不等同于 Bear 的 iCloud 同步或所有功能永不联网；本轮无网络审计。扩展需要页面内容访问权限，未操作权限，也不将官网建议授予所有网站权限当作必要的安全推荐。
