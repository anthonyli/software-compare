## 本批新增

| 产品 | 分类 |
|---|---|

| FilmCraft | 视频剪辑 |
| SoundCraft | 音频编辑 |
| PdfCraft | PDF 工具 |
| DesignCraft | 桌面排版 |
| AniCraft | 2D 动画 |
| EffectCraft | 视觉合成 |
| ArtCraft | AI 图像工作流 |

## 后续专门类别候选

WordCraft、GridCraft、DeckCraft：分别需要文字处理、电子表格、演示制作类别；CadCraft：CAD；TextureCraft / MaterialCraft：纹理绘制与材质设计；Craft Launcher：Craft 应用安装管理器，不等同于 Alfred/Raycast 式全局启动器。先核对官方边界，再按分类封面规范和对照工具建类，不塞错类。
