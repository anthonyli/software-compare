# Photoshop 替代方向补充（2026-11-14）

main 9519141，开始时无 open PR/Issue。Issue #79；图像编辑 7→9，保留既有开源选项。

## Affinity — Pixel

当前统一 Affinity 应用的桌面 Pixel，不是旧 Photo V2，和现有 Layout 是同一应用不同工作区。
- https://www.affinity.studio/photo-editing-software ：图层、绘画、RAW、蒙版和非破坏调整。
- https://www.affinity.studio/digital-illustration-software ：数字插画。
- https://www.affinity.studio/get-affinity ：账号及免费个人工具、付费 Canva AI。
- https://www.affinity.studio/ ：桌面平台、iPad 已发布；本条只比桌面，不能说 iPad 未发布。
- https://www.affinity.studio/it_it/help/affinity-online-authenticate/ ：30 天联网认证；与 get-affinity 长期离线描述冲突，所以不承诺永久离线，以当前版本为准。

逐帧时间轴和当前插件兼容未核实，标 unknown，不套用 Photo V2。官网兼容性宣传不等于已实测所有 PSD 无损往返。

## Photopea

- https://www.photopea.com/learn/ 与 https://www.photopea.com/learn/opening-saving ：Web 编辑器及 PSD 开存。
- https://www.photopea.com/learn/brush-tools ：画笔绘画。
- https://www.photopea.com/learn/animations ：图层/组命名为帧，GIF/APNG/WebP，逐帧标 partial，与本类 GIMP 边界一致。
- https://www.photopea.com/api/plugins ：网页面板 Live Messaging 插件能访问文档；不是 Photoshop 原生插件兼容保证。
- https://www.photopea.com/privacy.html ：免费作品可商用；Premium 有期限单次支付，不自动续订。普通文件编辑本地处理，但网盘与账户/插件另核数据流。公开 GitHub 反馈仓库不是编辑器开源许可。

没有安装或上传文件、启用 AI、运行作品处理，也没有实测 M4 性能。测试仅验证本站目录、翻译、响应式展示。未修改封面与生产设置。
