# LibreOffice PDF 导出密码/权限核实

核实于2026-11-16（UTC+8），Issue #305。只核实 PDF 工具表的 encrypt 维度，不表示其他字段当日重验。

官方来源：https://help.libreoffice.org/latest/en-US/text/shared/01/ref_pdf_export_security.html 。访问时为 LibreOffice 26.8 Help，描述 Export as PDF 的 Security 页，可设置打开密码及编辑/打印权限。因此从 unknown 改 yes，并移除“本次未核对”旧说明。

应严格区别打开密码与文档权限：官方提醒权限限制依赖符合相应 PDF 规范的阅读器，老阅读器可能不执行，低分辨率打印限制也并非所有阅读器遵守。不能承诺禁止截图、不可复制、不可破解或对任意接收者绝对保密；也不从本页推断加密算法强度。该证据是文档导出流程，不是对任意已有 PDF 无损重新加密或移除保护的保证。
