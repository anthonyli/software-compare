# Stash Mac
Verified 2026-11-15 UTC+8; documentation only, no installation, connection, certificate, helper or permission changes.

- https://stash.ws/macos : macOS 12.4+, Intel/Apple Silicon, Network Extension, privileged helper, process routing; continued use requires license.
- https://stash.ws/macos/pricing : observed GBP12 annual Personal/3 devices, GBP18 annual Family/6, GBP48 one-time Stash 4 Lifetime/6. Not future-major-version entitlement. No checkout/tax or auto-renewal claim.
- https://stash.wiki/en/faq/license-activation : iOS/iPadOS license works with iOS build on Apple Silicon, but not standalone Mac; reverse also not interchangeable.
- https://stash.wiki/en and https://stash.wiki/en/stash-mac : iCloud configuration/rules/subscription sync; Mac process routing. Independent engine with Clash configuration support, not a claim of complete compatibility with every third-party extension.
- https://stash.wiki/en/proxy-protocols/proxy-types : documented protocol types; no protocol connections tested.
- https://stash.ws/privacy-policy : vendor says no user traffic collection, permits non-personal/crash information, website uses analytics. No independent audit or anonymity claim. User-selected proxies/DNS and iCloud change data destinations.

This entry covers standalone Mac only. Official download page additionally labels Android/Windows early builds, not included in this row or assumed to share Mac capabilities/pricing. TUN partial is deliberately scoped to documented system traffic control via Network Extension. Commercial proprietary software, not open-source simply because Clash configuration is supported; enterprise rights not independently verified. No M4 benchmark.
