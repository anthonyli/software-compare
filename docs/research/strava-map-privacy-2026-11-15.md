# Strava map visibility versus third-party authorization

Verified 2026-11-15 (UTC+8), documentation only. Maintenance of the existing entry, not new software or an API test.

- https://support.strava.com/en-us/articles/15401779-app-authorization-settings (2026-09-18): activity-read permission covers Everyone/Followers activities, including hidden map portions. Private-activity read permission additionally includes Only You activities. Do not imply all apps can read all private activities.
- https://support.strava.com/en-us/articles/15402012-how-do-i-edit-my-map-visibility-on-strava (2026-09-14): Map Visibility applies on Strava and is not sent to other services with activities; it does not replace activity-level privacy controls.

No account access, authorization grants, settings changes, API requests with user data or activity uploads. Existing pricing, platform and feature ratings unchanged; this is a privacy caveat refresh, not full product retesting.
