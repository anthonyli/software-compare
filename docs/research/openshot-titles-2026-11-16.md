# OpenShot basic titles

Verified 2026-11-16 against the official 4.1 user guide https://www.openshot.org/files/user-guide/titles.html and official support article https://support.openshot.org/support/solutions/articles/43000625551-how-do-i-add-text-to-a-video-in-openshot- (updated 2023-07-26). Both describe the built-in basic title editor, SVG templates and title overlays above video. This supports the existing basic titles dimension. It does not claim automatic captions, universal SVG compatibility or self-contained advanced 3D titles. Advanced SVG editing uses external Inkscape; animated 3D titles require configured Blender.
