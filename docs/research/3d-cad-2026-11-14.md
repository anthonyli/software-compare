# 3D 与二维 CAD 扩充（2026-11-14）

Issue #53。未安装/实测软件，不制作、配音、渲染或交付视频。复用现有分类封面；旧 Blender 核实日期保持不变。

- QCAD CE：[官方功能表](https://www.qcad.org/en/features/) 区分 CE/Pro/CAM，CE 为 DXF R15/2000，DWG 和 SVG 导出为付费版，PDF 则社区版支持。[许可](https://www.qcad.org/en/license/) 为 GPLv3 带例外，Pro 商业插件单独授权。勿将 Pro 试用当作免费版能力。
- Maya：[功能与系统](https://www.autodesk.com/products/maya/product-details) 确认建模/绑定/动画/Arnold 与三桌面平台。[Arnold 说明](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-WhatsNew/files/GUID-82D13118-E987-4B5E-B1DA-C2A01F51058C.htm) 明确 GPU 渲染限 Windows/Linux NVIDIA，不承诺 M4 GPU 路径；购买订阅与试用不同。
- Cinema 4D：[产品](https://www.maxon.net/en/cinema-4d)、[角色动画](https://www.maxon.net/en/cinema-4d/features/character-animation)、[系统要求](https://support.maxon.net/hc/en-us/articles/16797414314012-System-Requirements-for-Maxon-Products)。完整桌面限 Windows/macOS，Linux 命令行渲染不能算完整桌面支持；Redshift 与节点许可不同。M4 16GB 达最低要求不代表复杂场景性能保证。
- Wings3D：[官网](https://www.wings3d.com/) 明确无动画。[仓库](https://github.com/dgud/wings) 及 license.terms 为宽松条款，不擅自指定 BSD 子版本；最终渲染依赖外部工具，骨骼绑定无明确证据故 unknown。
