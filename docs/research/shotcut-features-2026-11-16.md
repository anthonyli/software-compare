# Shotcut feature evidence

Checked 2026-11-16 Asia/Shanghai using https://shotcut.org/features/ . Documentation only; no installation, footage import, rendering, recording or video production.

Official features explicitly include keyframes for filter parameters, simple/advanced chroma-key filters and low-resolution proxy editing. These establish the three availability cells, not every filter parameter supporting keyframes, automatic clean keying for every source, or measured performance improvement. Proxy availability is not proof that proxies replace the full-resolution export source or an archival substitute for original media.

The same current page contains hardware/backend features and work-in-progress plugins. This batch does not generalize those statements to all installed releases, GPU models, codecs or platforms. GPU status remains unknown rather than implying universal acceleration. Existing release metadata/pricing/licenses are not reverified or changed. No full After Effects project compatibility claim follows from formats mentioned elsewhere on the page.

Only three capability cells and the direct source are changed; research and regression added. No blocked shared English file, homepage or cover edits. Local unit/cover tests and final-head CI required before merge; public-domain and automatic-deployment verification not claimed.
