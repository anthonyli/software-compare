main 6a2e5dc，开始前无 open issue/PR；Issue #77。现有四款保留，增加 Yaak 和 HTTPie Desktop。

## Yaak

- https://github.com/mountain-loop/yaak ：源码 MIT；源码自构建可商用，不等于官方预编译包工作用途免费。
- https://yaak.app/pricing 与 https://yaak.app/terms ：个人免费，商业年付/终身许可，30 天试用。首页与价格页终身金额不一致，不硬填金额。
- https://yaak.app/download ：Windows/macOS（含 Apple Silicon）/Linux。
- https://yaak.app/docs/getting-started/cli-usage ：官方 CLI 可运行本地工作区/文件夹请求，四个对比维度均支持。
- https://yaak.app/docs/getting-started/security-and-privacy ：本地 SQLite 不等于零联网；加密仅覆盖指定秘密值，不能概括整个数据库或响应历史。可选代理、OAuth hosted redirect、Git 和外部 Agent 分别核对数据去向。

## HTTPie Desktop

- https://httpie.io/desktop ：公开测试、桌面三平台、空间与集合。
- https://httpie.io/docs/desktop ：REST/GraphQL、集合及单请求命令导出；导出不等于原生集合 CLI，标 partial。匿名本地空间登录会同步；无账号不等于整个服务不收集元数据。
- https://github.com/httpie/desktop ：发行仓库，Linux AppImageLauncher 依赖；不套用 Terminal 开源许可。
- https://github.com/httpie/desktop/blob/master/LICENCE 指向 https://httpie.io/terms ，保留权利的专有条款允许个人及商业使用。
- https://httpie.io/privacy ：另有账户与服务数据处理政策。
- 完整价目未核实，显式保留未知，不将 AI preview 免费推广成整产品永远免费。
