# SVGEdit
Verified 2026-11-15 UTC+8 from official repository README and LICENSE-MIT.txt:
- https://github.com/SVG-Edit/svgedit

JavaScript SVG drawing editor for modern browsers. README supports recent Chrome/Firefox/Safari, documents local build/hosting with npm and svgcanvas, and embedding the editor into a dimensioned div. Canvas and UI are separate components. MIT permits commercial reuse with notices preserved; it does not license third-party assets automatically.

SVG and self-host yes; prototyping and collaboration unknown, rather than treating absent evidence as unsupported. No Illustrator AI fidelity promise. Browser pathway on M4 is not a runtime/performance result. Hosting/extensions/remote resource data flows were not audited; no pure-local/zero-upload guarantee. No installation, file upload or product execution. Not treating the official master demo as a pinned stable release.
