# Nutstore conflict handling evidence

Verified 2026-11-19 for issue #615. Only the existing `conflict` feature changes from unknown to yes.

- https://help.jianguoyun.com/?p=1129 (2020-03-03): the desktop client retains the cloud file and renames local modifications as a conflict copy; both are synchronized. If contents differ, users compare and manually incorporate changes. Windows naming differs from macOS/Linux.
- https://help.jianguoyun.com/?p=4031 (2023-11-11): repeats the conflict-copy mechanism and documents bulk handling in Windows client 7.0+ and 4.0+. Choosing a retained version or merging folders must not be described as semantic merging of arbitrary document contents.

These are currently accessible official help articles, not a claim about a newly released version. `yes` means conflict handling via preserved copies, not conflict-free collaboration or automatic content merge. No assertion of equivalent mobile UI, all-plan entitlements, or unlimited retention. Pricing, encryption, selective sync and ignore rules remain untouched. One English note is added; all existing dictionary entries remain unchanged. No client installation, real account or production-site access is needed.
