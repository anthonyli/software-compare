# Tenacity license evidence

Issue #503. Official documentation reviewed 2026-11-19 (Asia/Shanghai); no installed-app test.

https://tenacityaudio.org/docs/

The manual identifies the software license as GPL version 2 or later, both in its introduction and in the software notice. It covers the 1.3.x series. This establishes GPL-2.0-or-later rather than an inference from GitHub NOASSERTION or the upstream project's license. The manual itself is CC BY 4.0: that documentation license is not the application's license. This records the project's stated license, not a legal audit of every bundled dependency or third-party asset. Pricing, platforms, release snapshot and capabilities are unchanged.
