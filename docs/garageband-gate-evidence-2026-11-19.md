# GarageBand noise gate evidence

Issue #500. Official documentation checked 2026-11-19 (Asia/Shanghai), not an installed-app or audio-quality test.

Apple’s support article (published 2025-03-18) explains reducing low-level unwanted noise during silent passages with the track gate. The current iPhone Audio Recorder guide (2.3.20 selector) explains threshold gating for low-level input noise. This supports partial noise reduction, explicitly identified as Noise Gate, not unrestricted spectral denoising or restoration of noise underneath wanted audio. Keep spectral=no and all pricing, platform and other feature snapshots unchanged. Older desktop UI terminology is not a claim about current menu locations.
