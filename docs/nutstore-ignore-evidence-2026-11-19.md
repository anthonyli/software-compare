# Nutstore user-defined ignore rules

Verified 2026-11-19. Only ignore_rules changes from unknown to yes.

Official source: https://help.jianguoyun.com/?p=4159 (published 2022-03-11, still accessible and linked from the current synchronization FAQ archive). The article explicitly concerns the Windows client. Item 10 describes files/folders not synchronizing because of the user's own ignore rules. This establishes configurable exclusion, not merely built-in temporary-file filtering.

Scope: Windows support is verified. No assertion of gitignore compatibility, regex/glob syntax, current UI location, equivalent mobile/macOS/Linux configuration or plan entitlements. Other features, prices and existing English entries are unchanged. No software installed or actual user files excluded; no production access.
