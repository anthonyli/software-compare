# Notesnook editor and web clipper evidence

Issue #429. Checked 2026-11-18 against official stable v3.4.13, commit 4fc6fb4235c5834905f57b9bd82098bec2cd95cb.

The editor toolbar documents basic rich-text formatting and block insertion. Custom toolbar arrangements require Pro; marking basic rich-text support does not claim every advanced editor option is free.

The official extension is available for Chromium and Firefox. It connects to the Notesnook web app to save/sync clips; the app must remain available in the browser. Screenshot and complete-with-styles modes require sign-in and consume attachment quota. Basic clipping support is not a claim of universal browser/page compatibility, standalone clipping or unlimited storage. Existing price, trial, attachment and security caveats remain unchanged.
