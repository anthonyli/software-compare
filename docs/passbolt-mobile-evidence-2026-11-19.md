# Passbolt mobile applications

Issue #519. Verified 2026-11-19 from official quickstart documentation, not an installed-app test.

- https://www.passbolt.com/docs/user/quickstart/mobile/
- https://www.passbolt.com/docs/user/quickstart/mobile/android/
- https://www.passbolt.com/docs/user/quickstart/mobile/ios/

The mobile overview covers CE, Pro and Cloud and links Android and iOS setup. Both platform guides require an existing account configured through a desktop browser extension, the server URL and HTTPS. Account creation is not available in the mobile app; self-signed TLS certificates require device import. Therefore mobile application availability is supported and Android/iOS are included in platforms. This does not establish offline availability, feature parity, desktop clients or new prices. Other fields remain unchanged. No accounts, certificates or permissions were configured.
