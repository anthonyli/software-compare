# AI 比较范围与方法

按用户 2026-11-13 截图及后续保留指示，AI 区仅展示：AI 聊天助手、AI 编程工具、AI 图像工作流。非 AI 分类不受影响。

- 分类参考 https://ai-bot.cn/ ，不把导航站宣传文案当作能力或质量证明。
- 原本地 AI 类的 Ollama、LM Studio、Jan 迁入聊天助手。它们仍是不同产品形态，不能以模型效果直接横比；旧分类/产品链接 301 到新位置。
- 原有来源、许可证、限制、特色字段保留；合并后的新维度若没有证据，填“未知”，不推断“不支持”。聊天能力参见 https://docs.ollama.com/quickstart 、https://lmstudio.ai/docs/app 、https://www.jan.ai/ 。
- 选型先比较任务和产品形态，再比较平台、数据去向、模型依赖、操作权限与总成本。产品不是模型；本地客户端也不等于所有流程不出网；订阅不等于 API 额度；代码许可不等于模型或输出许可。
- 编程工具重点看 CLI/IDE、编辑与执行边界、审批与差异审查；图像工作流重点看制作流程、模型/节点依赖、许可和硬件。没有已核实证据的维度仅作为核对提示，不编造产品支持状态。
- 现有表格是官方文档能力对照，不是实测排行榜。Star、点赞、功能勾选数不能合成质量分。效果测试需固定任务、模型/版本、预算、机器和成功标准；本轮未安装、执行或付费测试收录产品。

后续如增加结构化筛选，可按产品形态、云/本地、费用结构和数据处理方式补字段；先逐项附官方来源与日期，再用于筛选。避免先做打分界面后补虚构数据。
