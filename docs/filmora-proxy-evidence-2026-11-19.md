# Filmora desktop proxy editing

Verified 2026-11-19. Only `filmora.proxy` changes from unknown to yes.

## Official sources
- https://filmora.wondershare.com/guide/proxy-video-editing.html documents automatic proxies above a chosen resolution threshold, manual Create Proxy File, lower-resolution editing copies, and original-media final export.
- https://filmora.wondershare.com/guide-mac/working-with-proxy.html independently documents automatic proxy creation and management in the Mac guide.

## Boundaries
This is capability evidence for desktop Filmora, not an assertion that the commercial application is free or that all exports are watermark-free. Existing pricing and trial caveats remain unchanged. The current unversioned guides support the current workflow, not a guarantee for every historical version. We do not copy inconsistent platform-version banners or old shortcuts as requirements. Proxies take generation time and storage; retain original media. No claim of guaranteed performance on M4/16GB, all codecs, mobile parity, free 4K export or universal GPU acceleration. Keyframes, chroma key, 4K export and GPU fields remain unknown.
