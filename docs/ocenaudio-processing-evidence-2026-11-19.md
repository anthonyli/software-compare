# ocenaudio noise reduction and multi-format export

Issue #511. Verified 2026-11-19 from official release documentation, not an installed-app test.

https://www.ocenaudio.com/changelog

The current changelog lists 3.22.2, matching the recorded product snapshot. Version 3.21.2 fixes previewing noise reduction, directly establishing the built-in capability. Version 3.20.0 lists WMA export, a Musepack encoder, and Apple native AAC/ALAC encoding on macOS; 3.21.0 adds further saving combinations. This supports noise reduction and multi-format export, not every codec on every operating system. No quality, unlimited format support, AI processing privacy or performance claim is made. Spectrogram viewing alone does not prove spectral editing, so that field, multitrack and batch remain unknown. Pricing, platforms and other metadata are unchanged.
