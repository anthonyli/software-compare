# Audio capability verification

Checked 2026-11-18. No application was installed or exercised.

- ocenaudio: https://www.ocenaudio.com/changelog . Version 3.22.0 notes microphone permission during recording; 3.21.2 describes stereo input recording and Linux recording fixes. This establishes basic recording, not a blanket claim about application/system capture or multitrack editing. The audio-recorders category already records microphone support; this removes the inconsistent unknown in audio-editors.
- Hydrogen 1.2.7: https://github.com/hydrogen-music/hydrogen/blob/712c25f5bd42942edcb927cd3668f21991efbee2/src/gui/src/ExportSongDialog.cpp . The export dialog maps FLAC, WAV, AIFF and other formats to the export settings. This establishes multiple audio output formats, not every optional codec on every build, or redistribution permission for samples.

Only two capability values and their official evidence links change. All other features, prices, versions, shared English mappings and homepage files are preserved.
