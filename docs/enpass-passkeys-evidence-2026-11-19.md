# Enpass passkey support

Issue #527. Verified 2026-11-19 from official personal documentation, not an installed-app or authentication test.

https://help.enpass.io/personal/latest/all/creating-storing-passkeys
https://help.enpass.io/personal/latest/all/auto-filling-passwords-passkeys-and-more

Enpass documents creating and storing account passkeys on desktop, iOS and Android, plus using saved passkeys through autofill. Setup requires configuring Enpass as the credential provider; desktop autofill uses a connected browser extension, and mobile autofill must be enabled. The target service must offer passkeys. This verifies the generic passkeys capability, not every browser/OS combination, vault-unlock authentication, key export/import or a change to plan pricing. Other capability and pricing records remain unchanged. No credentials were entered or accounts configured.
