# Bitwarden Password Manager integrated TOTP

Issue #543. Official documentation verified 2026-11-19; no account or authentication testing.

https://bitwarden.com/help/integrated-authenticator/

All accounts can store authenticator keys. Generating codes inside Password Manager requires Premium or membership in a paid Families, Teams, or Enterprise organization. The existing TOTP feature describes integrated code generation, so `paid` is appropriate, not unconditional `yes` or `no`. This is separate from the standalone Bitwarden Authenticator app and from using two-factor login to protect a Bitwarden account.

Only this product's TOTP status and source list change. Prices, license, unrelated unknown features, standalone Authenticator data and shared translation dictionaries remain untouched. No claim that free accounts cannot store keys is made.
