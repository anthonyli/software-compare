# ocenaudio batch processing evidence

Verified 2026-11-19. Only ocenaudio.batch changes from unknown to yes.

Official source: https://www.ocenaudio.com/changelog . The currently published version is 3.22.2, matching the existing record. Its release history records fixes for processing multiple files with VST (3.19.2), applying effects to many files on macOS (3.19.4), and batch export destination handling (3.19.5). These explicitly establish multi-file processing and export, not merely selecting several regions in one file. Later listed releases do not announce removal of this capability.

This is not a claim of a scripting API, unattended workflow automation, arbitrary effect chains or bug-free handling of every plugin. Spectral editing and multitrack remain unknown. No price/license/platform or release metadata changes.

Unit tests and English/Chinese desktop/mobile browser regression cover the status. No shared dictionary edits, production configuration/access or video rendering.
