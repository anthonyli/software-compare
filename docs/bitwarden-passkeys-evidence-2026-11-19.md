# Bitwarden Password Manager passkeys

Issue #529. Verified 2026-11-19 from official documentation, not an account or device test. Separate from Authenticator issue #406.

https://bitwarden.com/help/storing-passkeys/

The official guide confirms creating, storing and using external-service passkeys. Browser-extension settings must allow passkeys; excluded domains do not prompt. Mobile support requires configured providers and iOS 17+ or Android 14+; Android third-party providers do not support non-discoverable second-factor credentials. Only one passkey fits each login item. Current desktop instructions are platform-specific, not a promise about every listed OS or the recorded older desktop release. This capability is distinct from logging into or unlocking Bitwarden itself. No change to pricing, licenses, other features or release snapshots, and no claim that every passkey workflow is universally available.
