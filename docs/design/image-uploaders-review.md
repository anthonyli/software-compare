# 图片与文件上传工具分类封面

- Slug：`image-uploaders`，归入「文件工具」。仅比较上传客户端，存储与 CDN 是另外一层。
- 在 `category-cover-spec.json` 登记浅靛蓝色 `#E8EDF8` 和专用场景；`node scripts/category-cover-prompt.mjs image-uploaders` 输出组合提示词。素材：`site/public/categories/image-uploaders.svg`。
- 480×260；22 px 稀疏点阵和柔白角部光斑。图像、折角纸、向上箭头及链环表示上传文件后产生链接；无可读文字、产品商标、外链或脚本。
- 与网页离线存档、Finder 文件移动及快捷翻译封面按 340×184、170×92 并排验收。两个尺寸均可分辨上传方向与链接，主体不切边；静态验收不替代浏览器验证。
