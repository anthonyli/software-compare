# 快捷翻译与 OCR 分类封面

- Slug：`quick-translation-ocr`，归入「办公效率」，与截图工具的主用途分开。
- 在 `category-cover-spec.json` 登记浅玫瑰色 `#F8EAF1` 和专用场景；`node scripts/category-cover-prompt.mjs quick-translation-ocr` 输出组合提示词。素材：`site/public/categories/quick-translation-ocr.svg`。
- 480×260；22 px 稀疏点阵、柔白角部光斑。左卡用四个选区角表达截屏取字，右卡用浅色结果条承接；连接箭头表达处理方向。无文字、品牌、外链或脚本。
- 验收尺寸 340×184、170×92，新图与清理、录屏和网页封装封面并排。不同于网页封装的独立应用图标，识别选区和结果仍能区分，主体不切边。静态封面验收不替代响应式浏览器测试。
