# 网页封装桌面应用分类封面

- Slug：`website-to-desktop`，归入「开发工具」。与浏览器、网页离线存档分开。
- 在 `category-cover-spec.json` 登记浅杏色 `#F8EFE4` 和专用场景；`node scripts/category-cover-prompt.mjs website-to-desktop` 输出组合提示词。素材：`site/public/categories/website-to-desktop.svg`。
- 480×260；22 px 稀疏点阵、柔白角部光斑、白色网页窗格和无品牌的独立应用图标，中间是一枚黑色变换箭头。无文字、品牌、外链或脚本。
- 将新图和清理、录屏、网页离线存档的封面按 340×184、170×92 并排渲染。两种尺寸下轮廓和变换方向可辨，机身与箭头都未裁切。静态封面检查不替代响应式浏览器测试。
