# Telegram 桌面客户端分类封面

- Slug：`telegram-desktop-clients`，归入「网络工具」。范围仅是上游 Qt 客户端与桌面分支。
- 在 `category-cover-spec.json` 登记浅青色 `#E5F3F4` 和专用场景；`node scripts/category-cover-prompt.mjs telegram-desktop-clients` 输出组合提示词。素材：`site/public/categories/telegram-desktop-clients.svg`。
- 480×260；22 px 稀疏点阵和柔白角部光斑。错叠桌面窗口和无字消息块表达客户端对照，不用纸飞机、产品商标、可读文字、外链或脚本。
- 与浏览器、AI 聊天及个人助理封面按 340×184、170×92 并排验收。两种尺寸均可辨认桌面窗口层次和消息块，主体不切边；静态验收不替代浏览器验证。
