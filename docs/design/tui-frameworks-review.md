# Terminal UI framework category cover

The 480×260 illustration uses a pale blue #E8EFF8 palette registered in both the cover spec and category tint. It keeps the reference family's 22 px sparse dot grid, soft corner highlights, white rounded shapes, restrained shadows, and black #111111 details. The selected row, neighboring chart pane, and directional keys distinguish it from the CLI framework cover. There are no words, logos, fonts, or linked assets.

Generated the combined design prompt with `node scripts/category-cover-prompt.mjs tui-frameworks` without using the main-cover prompt. Rendered the SVG alongside `cleaners.svg` and `screen-recorders.svg` at 340×184 and 170×92 using the installed Sharp renderer. Visual review found consistent light and spacing, a legible split terminal panel at both scales, and no clipped shapes. These static renders do not replace responsive browser verification.

An independent reviewer also rendered and inspected a 340×184 grid with Cleaners and Screen Recorders above CLI and TUI. The TUI is visually distinct from CLI while retaining the same color treatment, dot pattern, white forms and light shadows. The two comparison renders are local review artifacts, not production screenshots.
