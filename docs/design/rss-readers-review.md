# RSS 阅读器分类封面

- Slug：`rss-readers`，归入「办公效率」，不把网站订阅和音乐串流合并。
- 在 `category-cover-spec.json` 登记浅杏橙色 `#F9EDDF` 和专用场景；`node scripts/category-cover-prompt.mjs rss-readers` 输出组合提示词。素材：`site/public/categories/rss-readers.svg`。
- 480×260；22 px 稀疏点阵和柔白角部光斑。用叠放的阅读卡片、摘要短线和接收曲线表达持续订阅。无可读文字、第三方标识、外链或脚本。
- 与录屏、输入源切换和中文输入法封面按 340×184、170×92 并排验收。两个尺寸均能辨认阅读卡与订阅曲线，主体未裁切；静态验收不替代浏览器验证。
